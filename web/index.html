    How to print

    1. Open your model. Export an STL, then drop it on the bed. Tinkercad: Export → .STL. Onshape: right-click the part → Export → STL. Fusion 360: File → Export → STL. Blender: File → Export → STL.
    2. Set it on the bed. Drag it to move it. Use Rotate → Lay flat so a flat side is down. Red parts hang in the air and need supports.
    3. Pick your settings. The class settings work for most prints. Change them only if you know why.
    4. Slice, then save to the SD card. Slicing works when your teacher opens it: type the class phrase from the board the first time. Pick the class SD card in the save window, eject it, then carry it to the printer.
    5. Print. Pick your file on the printer screen. Your teacher starts every print.
